如何把工作台发给团队

  • 本页为单文件网页，将 HTML 文件发送给对方（U 盘 / 网盘 / 微信），对方双击即可在任意电脑浏览器打开，无需联网。
  • 提示词中的 [Subject] 占位符会自动替换为「角色替换」框中填写的名称，复制即用。
  • 浏览器内按 Ctrl/Cmd + P 可打印或导出 PDF，方便线下评审与提案归档。

建议的使用流程

  • 定调期：用「随机灵感」快速扫方向，建立风格备选清单
  • 定标期：按卷目逐条取用，锁定期权上的镜头语言
  • 生成期：复制提示词喂给文生图 / 图生视频 / 视频生成模型
  • 沉淀期：归档配色卡与风格参考方案，保持全季一致
